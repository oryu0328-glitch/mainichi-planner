まいにち手帳 Ver.2.44 — GitHub Pages 更新用

【今回の主な修正】
1. 予定の開始・終了時刻を、数字と「:」の直接入力ではなくホイール式で選択します。
2. 時は00〜29、分は00〜59を1分単位で選べます。
3. 月曜19:00〜翌火曜01:00の仕事は、月曜19:00〜25:00として登録できます。
4. 終了が24:00〜29:59の予定は、月・週・日・ホームの予定表示で開始日にまとめ、翌日には重複表示しません。
5. 旧版で終了日が翌日・終了時刻が01:00などになっていた予定も、深夜06:00より前の終了なら開始日側に表示します。編集して保存すると25:00形式に統一できます。
6. 目標・履歴の予定時間は開始日に計上し、24時間の生活分析は実際の暦日ごとの時間帯で計上します。
7. 予定・ToDo・メモ・フォルダ・カテゴリー・睡眠・分析などの保存キーと既存データ形式は維持します。
8. Ver.2.43のピンクのカレンダー・ハート・花のアイコンは変更していません。

【入力例】
月曜日の仕事 19:00〜翌朝01:00
・開始日：月曜日、終了日：月曜日
・開始時刻：19:00
・終了時刻：25:00（または01:00を選ぶと自動で25:00に補正）
・保存後、月曜日の予定に表示され、火曜日の予定一覧には重複表示されません。

【更新前の注意】
データは端末・ブラウザ内の保存領域にあります。更新前に「設定 → データ管理 → バックアップを保存」でJSONバックアップを保存してください。
GitHub Pagesの公開URLを変更したり、ブラウザのサイトデータを消したりしないでください。

【GitHubへの更新】
1. ZIPを解凍します。
2. 解凍したファイルをすべて、既存のGitHubリポジトリのルートにアップロードします。
3. Commit message: Update Mainichi Planner v2.44
4. Extended description: Add an iOS-style scroll-wheel event time picker with support for 00:00–29:59. Keep overnight events on their starting calendar date without duplicate next-day display. Update timeline and analysis calculations while preserving existing user data and app icons.
5. Commit directly to the main branch → Commit changes を選択します。
6. 公開ページを再読み込みして動作を確認します。

【更新後の確認】
・開始と終了の時刻をタップするとホイールが開くか
・終了25:00で保存できるか
・月曜日19:00〜25:00の予定が火曜日に重複しないか
・日・週の時間軸に25:00が表示されるか
・以前の予定、ToDo、メモ、カテゴリー、睡眠の記録が残っているか

※標準iOS時刻入力のホイールでは29時まで選択できないため、アプリ内の独自ホイールを使用しています。
